# Roadmap — Discipline World

Standalone project. **No mains-tracker integration.**

Core loop first: **4 days → tree · 6 days → cherry blossom · good marks → fruits.**

---

## Phase 0 — Foundation (current)

- [x] Vision + independence from mains tracker
- [x] Canonical progression (4 / 6 / fruits)
- [x] Mock study log + world state
- [ ] Unity 6 URP project under `unity/`
- [ ] Local study log writer (manual or timer) inside my-garden only

---

## Phase 1 — Empty world

- Third-person walk in a small peaceful clearing
- Day-night + ambient audio
- Save logout position
- No dashboards

---

## Phase 2 — Core progression

- Log daily hours in my-garden
- **4 continuous ≥6h days → one tree**
- **6 continuous ≥6h days → cherry blossom**
- **Log good test score → fruits**
- Interact tree → see plant date / blossom / fruit / marks

Exit criteria: four real study days → tree appears and stays; six days → blossoms; score → fruit.

---

## Phase 3 — Feel

- Plant seed by walking to a patch (optional)
- Delayed “morning growth” cinematic
- Species variety
- Leaf health (optional)

---

## Phase 4+ — Vision layers

Weather, regions, rivers, wildlife, cabin — only after core loop is solid.

---

## Non-goals

- Reading CGPSC mains tracker DB / API / Godot feed
- In-game shops, XP economies, multiplayer
- Huge empty map
